# Raw API captures

Each timestamped directory is one public API capture. Response files listed in `manifest.json` are exact bytes returned by the server; the manifest records URL, time, status, and SHA-256. `selected_markets.json` and `selection.json` are local collection metadata. Failed HTTP responses remain available for inspection. Earlier exploratory runs are retained; use the run identified in the feasibility report for the reviewed prototype.

Raw responses contain public proxy-wallet addresses and API profile fields. Clean analytical tables omit profile names, biographies, and images. No API credentials or private wallet keys are used.
